# notes → html

## 輸入
`notes/NN_主題.md`：自由格式的內容筆記，可以很長。

## 輸出
`html/NN_主題.html`：以 `html/_template.html` 為底，**只改 `data-*` 欄位與文字**，不改 CSS 與結構。

## 欄位與字數上限（生圖模型寫中文越短越不會錯）
| 欄位 | 位置 | 上限 |
|---|---|---|
| `data-series` | 頂部膠囊 | 固定「看懂中風 AI 教學圖卡」 |
| `title` | 大標題 | 12 字 |
| `subtitle` | 副標 | 14 字 |
| `block` ×3 | ①②③ 便利貼 | 小標題 6 字；內文 34 字 |
| `block` 的 `data-icon` | 小插圖描述（英文，給生圖用，不會印出） | 一句 |
| `bubble` | 吉祥物對話框 | 14 字 |
| `footer` | 頁腳 | 固定作者列＋頁碼 `n/3` |

## 步驟
1. 讀筆記，挑出讀者最需要的三件事，依序放成「它是什麼 → 怎麼算／怎麼用 → 要小心」。
2. 每塊內文改寫成白話短句，數字照原文，不四捨五入。
3. 對話框放一句可以記住的重點。
4. 用瀏覽器打開 html 檢查：字數沒超過、沒有錯字、三塊順序合理。
5. 不放任何插圖；插圖由下一步的生圖模型依 `data-icon` 畫。
